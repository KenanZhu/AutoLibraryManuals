## 工具简介

AutoLibrary 是一款专为北京建筑大学图书馆设计的自动化工具，旨在帮助学生简化图书馆座位操作流程，节省宝贵时间。

### 工具特点

> 本文主要概述了在 Windows 11/10 环境下的 AutoLibrary 工具的安装、配置和使用方法。

## 功能介绍

**自动预约** — 如果用户当前没有有效预约时，工具会自动为您预约指定座位。
> **适用场景：** 提前预约第二天的座位

**自动签到** — 如果用户当前已有预约，且在可签到时间范围（开始时间的前后30分钟）内，工具会自动完成签到。
> **适用场景：** 因忘记签到而导致失约，影响正常使用

**自动续约** — 如果用户当前正在使用座位，且到达可续约时间（结束时间前的120分钟），工具会自动延长使用时间。
> **适用场景：** 需要长时间使用座位

### 模式组合使用

运行模式可以组合使用，只需在配置窗口中勾选对应模式即可：

**定时任务** — 使用内置定时任务管理，添加定时任务，指定时间后按当前预约信息自动运行。
支持设置重复周期，如每周一、周三、周五等执行预约操作。

![功能介绍-定时任务](/assets/images/v1.2.1/功能介绍-定时任务.png)
> **适用场景：** 定时执行预约、签到、续约操作

## 准备工作

### 安装工具

#### 下载软件

请从 [AutoLibrary 下载页面](/downloads) 下载最新版本的工具。

**Github**：下载页面更新较为及时，但网络连接不稳定，速度较慢。
**云盘下载**：版本更新略有延迟，但下载速度更快。

#### 版本类型

从 v1.1.0 版本开始，提供两种版本供您选择：

- 便携压缩包版本
- 安装器版本

> **重要：**压缩包内的 `_internal` 文件夹与 `AutoLibrary.exe` 可执行文件需要位于同一目录下，请勿修改或移动这两个文件，否则可能导致工具无法正常运行。

### 配置浏览器驱动

工具需要通过浏览器驱动来控制浏览器。以下两种方式可以帮助您快速配置驱动：

> **提示：**AutoLibrary 支持自动检测本地安装的浏览器，并查找适配的驱动版本，大大简化了配置流程。

#### 方式一：使用浏览器驱动自动下载功能（推荐）

![浏览器驱动自动下载窗口](/assets/images/v1.2.1/浏览器驱动自动下载窗口.png)

**操作步骤：**

1. 在 AutoLibrary 配置界面中，点击"浏览器驱动自动下载"按钮，打开驱动下载窗口
2. 工具会自动检测您电脑上已安装的浏览器，并列出可用的驱动版本
3. 选择需要的浏览器驱动版本，点击"开始下载"按钮
4. 下载完成后，点击"确定"保存并退出对话框，即可在配置界面中使用该驱动

![开始下载浏览器驱动](/assets/images/v1.2.1/浏览器驱动自动下载窗口-开始下载.png)

![浏览器驱动下载完成](/assets/images/v1.2.1/浏览器驱动自动下载窗口-下载完成.png)

#### 方式二：手动下载浏览器驱动

如果您仍需手动下载驱动，请根据您使用的浏览器选择对应的驱动：

- **Microsoft Edge** — 适用于Windows 10/11系统 [下载驱动](https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/)
- **Google Chrome** — 最常用的浏览器 [下载驱动](https://developer.chrome.google.cn/docs/chromedriver/downloads)
- **Mozilla Firefox** — 开源浏览器 [下载驱动](https://github.com/mozilla/geckodriver/releases)

## 使用步骤

### 启动工具

双击运行 AutoLibrary.exe 文件，工具将启动主界面。

> **提示：**软件首次启动，未初始化配置文件，直接运行脚本会提示失败。

![运行主界面](/assets/images/v1.2.1/运行主界面.png)

### 配置工具

**使用界面配置** — 点击主界面窗口右上角的配置按钮，打开配置窗口。

![配置窗口-用户配置](/assets/images/v1.2.1/配置窗口-用户配置.png)
> **提示：**初次运行软件时，用户配置默认为空，需要手动添加。

#### 用户列表

| 功能 | 说明 | 备注 |
| --- | --- | --- |
| 用户列表 | 显示当前配置文件中的所有用户 | 支持添加、删除用户操作，选中用户项进行详细配置 |

#### 用户信息

| 参数 | 说明 | 默认值/可选值 |
| --- | --- | --- |
| 学号 | 用户的学号 | 必填项，用于登录图书馆系统 |
| 密码 | 用户的密码 | 默认值为"000000"，请根据实际情况修改 |

#### 预约信息

| 参数 | 说明 | 默认值/可选值 |
| --- | --- | --- |
| 日期 | 座位预约日期 | 格式：yyyy-MM-dd，默认显示当前日期（18:00-23:00可预约次日） |
| 地点 | 预约座位的地点 | 默认值："图书馆" |
| 楼层 | 预约座位的楼层 | 默认值："二层"，可选："二层"、"三层"、"四层"、"五层" |
| 区域 | 预约座位的区域 | 默认值："二层内环" ，可选随楼层变化 |
| 座位号 | 预约座位的座位号 | 例如："12A"、"012a"等 |
| 开始时间 | 预约座位的开始时间 | 格式：HH:mm，默认当前时间，可选范围：7:30-23:30 |
| 结束时间 | 预约座位的结束时间 | 格式：HH:mm，默认当前时间+2小时，可选范围同开始时间 |
| 最大时间偏差 | 时间不可用时的最大偏差范围 | 单位：分钟，可选范围：0-120，0表示严格按选择时间 |
| 优先最早/晚 | 当最大时间偏差范围内存在多个可选时间时的优先选择 | 开始时间优先最早，结束/续约时间优先最晚 |
| 期望预约时长 | 预约座位的期望时长 | 单位：小时，可选范围：0-8，默认：2小时 |
| 期望续约时长 | 座位的期望续约时长 | 单位：小时，可选范围：0-4，默认：1小时 |
| 优先满足期望时长 | 是否优先满足时长限制 | 勾选后 AutoLibrary 会尽量满足期望预约时长，但是可能因座位紧张导致预约失败 |

### 手动运行任务

配置完成后，点击主界面窗口底部左侧的"开始运行脚本"按钮，工具将按配置自动执行预约、签到、续约等操作。

> **提示：**任务将同时处理所有启用的用户及任务组。

### 定时任务

点击主界面窗口底部左侧的"定时任务管理"按钮，打开定时任务管理窗口。

![定时任务管理窗口](/assets/images/v1.3.0/定时任务管理窗口.png)

#### 添加定时任务

点击"添加定时任务"按钮，在弹出的对话框中配置任务参数：

| 参数 | 说明 | 备注 |
| --- | --- | --- |
| 任务名称 | 定时任务的名称 | 用于识别任务，可自定义 |
| 定时类型 | 选择特定时间或相对时间 | 特定时间：指定具体执行时间；相对时间：从当前时间开始计算延时 |
| 运行模式 | 选择静默运行或运行前提示 | 静默运行：任务执行时不会弹出窗口；运行前提示：任务执行前会显示提示信息 |
| 重复执行 | 设置任务是否重复执行，并选择重复周期 | 全选或全不选则为每日执行 |

![添加定时任务对话框](/assets/images/v1.3.0/添加定时任务对话框.png)
> **提示：**添加定时任务后，任务将显示在列表中，状态为"等待中"。到达指定时间后自动执行。

#### 编辑定时任务

支持对已创建的定时任务进行编辑修改，无需删除重建。在定时任务管理窗口中，在任务列表中的任意任务项上单击鼠标右键，在弹出的菜单中选择"编辑"。编辑对话框将显示任务的当前配置。您可以修改任务名称、定时时间、运行模式等通用参数，你也可以将普通任务转换为可重复性任务，反之亦然。

![定时任务右键编辑菜单](/assets/images/v1.3.0/定时任务-右键编辑.png)
> **注意：**编辑任务时，任务的 UUID 和执行历史（如果为可重复性任务）将被保留。修改执行时间后，状态将重置为"等待中"。

也可通过右键菜单的"删除"选项，或点击任务项右侧的"删除"按钮来移除定时任务。

> **警告：**删除可重复性任务将同时清除该任务的所有执行历史记录。

## 故障排除

### 常见使用问题及解决方法

### 工具启动时报错"无法找到驱动 / Unable to obtain driver"等类似报错信息

这大概率是因为浏览器驱动未正确安装或版本不匹配。

**检查驱动位置** - 确认驱动文件是否放置在正确位置
**确认版本匹配** - 确认驱动版本与浏览器版本完全匹配，例如：Chrome 浏览器需要对应版本的 chromedriver.exe，切勿混用
**重新安装驱动** - 尝试重新下载并安装驱动

### 登录失败，提示账号密码错误

请检查配置界面中的账号密码是否正确。

**确认账号密码** - 确认学号和密码无误
**检查特殊字符** - 检查是否有不支持的特殊字符需要转义
**手动验证账号** - 尝试手动登录图书馆系统确认账号可用

### 预约失败，提示座位不可用

目标座位可能已被他人预约或不在可预约时间。

**确认座位信息** - 确认座位编号是否正确，是否在该楼层指定区域
**调整预约策略** - 尝试预约其它座位或调整预约时间，例如调整允许的开始或结束时间的最大偏差，位置紧张情况下可以让脚本根据允许的时间范围选择最佳起始时间

### 定时任务始终显示 "已就绪" 或 "执行中"，且无法删除

> **重要：**此解决方法需要直接操作 AutoLibrary 的核心配置文件，需要操作者对 JSON 文件格式有一定了解。操作前建议先备份相关文件，以免误操作导致配置丢失。

> 这一般是因为定时任务已经进入了预约队列，但是软件上次可能没有成功处理完就被意外关闭了。请按照以下步骤手动删除异常任务：

**记录异常任务信息** - 检查界面中正在运行的定时任务，记住任务名称或运行时间（任何能帮助你分辨该任务的信息），稍后需要在配置文件中定位它。
**找到配置文件目录** - 在 AutoLibrary 配置界面的「其它」选项卡中，找到「当前运行配置文件的路径」显示的文件夹路径，使用文件管理器打开该目录。
**打开定时任务配置文件** - 在该目录中找到名为 "timer_task.json" 的文件，使用文本编辑器（推荐使用 VS Code、Notepad++ 等代码编辑器，也可使用记事本）打开。
**定位异常任务** - 在 JSON 文件中查找包含以下信息的任务配置块：name（任务名称）、execute_time（执行时间）以及你在第一步中记录的其它信息。
**识别中文名称（如适用）** - 如果你的定时任务名称包含中文，在 JSON 文件中会以 Unicode 编码显示，例如："name": "预约任务"。要解码这些字符，可以复制包含 Unicode 的 "name" 字段整个值，使用在线工具搜索「Unicode 转中文」进行转换，确认是否匹配你的异常任务。
**删除异常任务** - 找到对应的任务配置块后，将其从 JSON 文件中完全删除。删除时请注意保持 JSON 格式完整，确保花括号 {}、方括号 []、逗号等符号正确，不要删除其它正常的任务配置，删除后保存文件。
**重启软件** - 完全关闭 AutoLibrary，然后重新打开。此时异常的定时任务应该已成功删除，界面状态恢复正常。

> **提示：**如果操作后 JSON 格式出错，软件可能会意外覆写原有配置文件。因此请务必备份重要的配置文件恢复，并检查 JSON 语法是否正确（注意最后一个元素后不要有多余的逗号）。

## 常见问题

### 使用 AutoLibrary 是否安全？

AutoLibrary完全模拟人工操作，不干扰图书馆系统正常运行。工具不会收集或上传您的个人信息，所有数据仅保存在本地配置文件中。

### 可以同时预约多个座位吗？

根据图书馆规定，每个账号同一时间段只能预约一个座位。但您可以在配置界面中添加多个账号，工具会依次处理每个账号的预约请求。
> **重要：**本工具软件旨在简化并辅助用户正常使用时的图书馆服务流程，请勿滥用影响他人及图书馆正常运行。

### 工具运行期间可以操作电脑吗？

可以正常使用电脑，但请勿操作工具自动打开的浏览器窗口，否则可能会干扰工具的正常运行。

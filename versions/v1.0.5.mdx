## 工具简介

AutoLibrary 是一款专为北京建筑大学图书馆设计的自动化工具，旨在帮助学生简化图书馆座位操作流程，节省宝贵时间。

本工具模拟人工操作，通过简单的界面配置并交互使用。

### 工具特点

## 功能介绍

**自动预约** — 如果用户当前没有有效预约时，工具会自动为您预约指定座位。
> **适用场景：** 提前预约第二天的座位

**自动签到** — 如果用户当前已有预约，且在可签到时间范围（开始时间的前后30分钟）内，工具会自动完成签到。
> **适用场景：** 因忘记签到而导致失约，影响正常使用

**自动续约** — 如果用户当前正在使用座位，且到达可续约时间（结束时间前的120分钟），工具会自动延长使用时间。
> **适用场景：** 需要长时间使用座位

### 模式组合使用

运行模式可以组合使用，只需在配置窗口中勾选对应模式即可：

**定时任务** — 使用内置定时任务管理，添加定时任务，指定时间后按当前预约信息自动运行。
![功能介绍-定时任务](/assets/images/v1.0.2/功能介绍-定时任务.png)
> **适用场景：** 定时执行预约、签到、续约操作

## 准备工作

### 下载浏览器驱动

工具需要通过浏览器驱动来控制浏览器，请根据您使用的浏览器下载对应版本的驱动：

- **Microsoft Edge** — 适用于Windows 10/11系统 [下载驱动](https://developer.microsoft.com/en-us/microsoft-edge/tools/webdriver/)
- **Google Chrome** — 最常用的浏览器 [下载驱动](https://developer.chrome.google.cn/docs/chromedriver/downloads)
- **Mozilla Firefox** — 开源浏览器 [下载驱动](https://github.com/mozilla/geckodriver/releases)

双击运行AutoLibrary.exe文件，工具将启动主界面。

| 期望续约时长 | 座位的期望续约时长 | 单位：小时，可选范围：0-4，默认：1小时 |
| 优先满足期望时长 | 是否优先满足时长限制 | 勾选后可能因座位紧张导致预约失败 |

2. 使用配置文件：在脚本可执行文件的根目录创建运行配置文件run.json和用户配置文件user.json。

用户配置文件

run.json文件控制工具的基本运行参数：

```
{
"library": {
"host_url": "http://10.1.20.7",
"login_url": "/login"
},
"mode": {
"run_mode": 1
},
"login": {
"auto_captcha": true,
"max_attempt": 3
},
"web_driver": {
"driver_type": "edge",
"driver_path": "msedgedriver.exe",
"headless": false
}
}
```

#### 参数说明

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| library/ |  |  |
| ./host_url | string | 图书馆主机URL，无需更改 |
| ./login_url | string | 登录页面URL，无需更改 |
| mode/ |  |  |
| ./run_mode | number | 运行模式，可组合使用（+1：自动预约，+2：自动签到, +4：自动续约） |
| login/ |  |  |
| ./auto_captcha | boolean | 自动验证码识别，建议保持true |
| ./max_attempt | number | 登录尝试次数，默认3次 |
| web_driver/ |  |  |
| ./driver_type | string | 浏览器类型（edge/chrome/firefox） |
| ./driver_path | string | 驱动文件路径 |
| ./headless | boolean | 无头模式，默认false（显示浏览器窗口） |

### 定时任务设置

#### 定时任务设置

你可以在软件中设置定时任务，让软件在指定时间自动运行。

![定时任务管理](/assets/images/v1.0.0/定时任务管理.png)

#### 定时任务管理

你可以在定时任务管理界面添加、删除、修改定时任务。

> **提示：**在队列中的任务，即已就绪和运行中任务无法删除，只能等待运行结束。

![定时任务添加](/assets/images/v1.0.0/定时任务添加.png)

定时时间分为特定时间和相对时间两种

| 定时选项 | 描述 |
| --- | --- |
| 特定时间 | 指定定时任务开始时间（格式：yyyy-MM-dd HH:mm:ss） |
| 相对时间 | 预约开始时间相对当前时间的偏移量（天，小时，分钟，秒） |

执行方式分为静默执行和运行前提示两种

| 执行方式 | 描述 |
| --- | --- |
| 静默执行 | 定时任务开始后，自动运行，执行结束后会在右下角显示系统通知 |
| 运行前提示 | 定时任务开始时，会显示主界面并显示系统通知 |

![定时任务](/assets/images/v1.0.0/定时任务.png)

#### 监控运行状态

你可以在软件中监控定时任务的运行状态，包括是否当前待运行，队列中，运行中，已执行任务数量。

![监控运行状态](/assets/images/v1.0.0/定时任务开始运行.png)

#### 运行结束

如果选择了静默执行，定时任务运行结束后，会在右下角显示系统通知。

如果选择了运行前提示，定时任务运行结束后，会在主界面显示系统通知。

![运行结束](/assets/images/v1.0.0/定时任务运行结束.png)
![运行结束提示](/assets/images/v1.0.0/定时任务运行结束提示.png)

### 监控运行状态

如果运行设置中没有勾选浏览器无头模式运行，工具会在运行过程中打开浏览器窗口，显示自动运行过程。

除此之外，你还可以通过软件的运行日志输出区域查看详细的运行状态和错误信息。

![监控运行状态](/assets/images/v1.0.0/监控运行状态-运行图.png)

### 查看运行结果

软件运行结束后日志会显示本次运行结果："处理完成, 共计 n 个用户, 成功 n 个用户, 失败 m 个用户, 跳过 s 个用户"。

经计算，图片中示例中共计划预约 5 个用户，1 个用户被预先设置为跳过，剩余 4 个用户中，3 个预约操作成功，另外一个由于时长超过最晚可预约时间，判定失败。人均预约时长在 3-4 秒左右，满足正常使用需求。

![查看运行结果](/assets/images/v1.0.0/监控运行状态-运行结果.png)

### 常见问题及解决方法

### 工具启动时报错"无法找到驱动/Unable to obtain driver"等类似报错信息

这是大概率是因为浏览器驱动未正确安装或版本不匹配。

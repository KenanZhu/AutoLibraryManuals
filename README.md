## 开发

安装 [Mintlify CLI](https://www.npmjs.com/package/mint) 以在本地预览文档更改：

```
npm i -g mint
```

在 `docs.json` 所在目录运行：

```
mint dev
```

在 `http://localhost:3000` 查看本地预览。

## 发布

更改推送到默认分支后将自动部署到生产环境。

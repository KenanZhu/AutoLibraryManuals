---

运行 AutoLibrary 文件，工具将启动主界面。

![运行主界面](/images/v1.2.1/main-ui.png)

软件首次启动时，未初始化配置文件，直接运行脚本会提示配置文件未找到。这属于预期行为，请先完成下方配置。

<Info>
  为适应不同的用户需求，这里分别提供了通过界面与直接修改配置文件两种方式，请按照需求参考选择。
</Info>

<Note>
  Windows 与 macOS 平台配置文件路径因系统而异，详见[通过文件配置](/zh/manual/v1.4.0/configuration/file)页面。
</Note>

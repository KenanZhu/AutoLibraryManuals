全局设置窗口，用于管理应用级别的设置。全局设置与脚本运行配置相互独立，修改后应用重启仍然生效。

## 打开方式

点击菜单栏中的 [**工具**] → [**全局设置**]，打开全局设置窗口。

![全局设置窗口](/images/v1.4.0/global-settings-window.png)

## 界面概览

全局设置窗口左侧为导航栏，右侧为设置内容区域。选择左侧导航项可切换到对应的设置页面。窗口底部为操作按钮：

| 按钮 | 功能 |
| --- | --- |
| [**取消**] | 放弃修改并关闭窗口 |
| [**应用**] | 保存当前设置但不关闭窗口 |
| [**确认**] | 保存设置并关闭窗口 |
